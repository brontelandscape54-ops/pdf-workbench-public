# 複数サムネイル選択時の手動一括編集

左サムネイルを⌘クリック／Shiftクリックして複数選択した場合、
追加のチェックボックスを使わず、**中央プレビューで実際に手動編集した結果**を
選択中の全頁へコピーする。複数選択しただけでは各頁の分割設定を変更しない。

- 中央で表示中の頁が選択対象に含まれるときだけ同期する。
- 同期は赤い分割線を離して編集が確定した時点、および分割・統合・
  OCR順変更・4分割／1領域プリセット・手動設定変更の確定時に実行する。
- 以前の分割数が違っていても、中央頁の分割木・位置・OCR順などの
  完成した設定で対象頁を上書きする。コピー後の各頁は独立した設定を持つ。
- 固定中の**他の頁**は同期から除外する。中央の固定頁そのものを直接編集する
  ことは可能で、固定頁から非固定頁へ設定をコピーすることも可能。
- 一つの手動操作で変更された複数頁はUndo/Redoでまとめて復元する。
- 複数選択したまま中央プレビューの頁を切り替えられる。
  中央頁が選択外の場合は、その頁からの一括編集は行わない。
- 自動分割タブの一括画像解析は各頁の内容を個別に解析する既存の処理を維持し、
  中央プレビューの結果をコピーする手動同期とは区別する。
- 保存形式の変更はない。`manifest.json`/`workspace.json` は従来のv1を維持する。

対象頁数および固定のため除外した頁数は、手動・出力タブ上部に表示する。
